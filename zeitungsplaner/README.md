# Seitenplaner Zeitung

Eine einzelne HTML-Datei (`index.html`) zum Planen von Zeitungsseiten. Einfach im Browser öffnen – keine Installation, kein Server nötig.

## Satzspiegel

| | |
|---|---|
| Breite | 277,5 mm |
| Höhe | 440 mm |
| Spalten | 6 (Spaltenbreite 45 mm, Zwischenschlag 1,5 mm) |
| Seite gesamt | 2.640 spmm (6 × 440 mm) |

Spaltenbreiten: 1 = 45 mm, 2 = 91,5 mm, 3 = 138 mm, 4 = 184,5 mm, 5 = 231 mm, 6 = 277,5 mm.

## Funktionen

- Flächen anlegen mit Spaltenzahl, Höhe in mm, Art (Artikel, Anzeige, Bild, Sonstiges) und Bezeichnung – z. B. 2 Spalten × 50 mm. Die Fläche landet an der ersten freien Stelle.
- Flächen mit der Maus verschieben: horizontal rasten sie in die Spalten ein, vertikal im gewählten Raster (1, 5 oder 10 mm).
- Mit gedrückter **Alt-Taste** (Mac: Option) ziehen: Die Fläche lässt sich frei platzieren, außerhalb des Spaltenrasters, in 0,5-mm-Schritten. Frei platzierte Flächen haben einen gestrichelten Rahmen; ohne Alt gezogen oder mit „Ins Raster setzen“ rasten sie wieder ein. Alt + Pfeiltasten verschiebt in 0,5-mm-Schritten, das Feld „Links (mm)“ setzt die Position exakt.
- Größe über die Ecke unten rechts ziehen oder exakt im Feld „Ausgewählte Fläche“ eingeben.
- Überlappende Flächen werden rot markiert.
- Belegung pro Seite in Spaltenmillimetern (belegt / frei / Prozent).
- Mehrere Seiten anlegen, umbenennen, duplizieren, löschen; Miniaturansicht in der Seitenliste.
- Tastatur: Pfeiltasten verschieben (mit Alt fein), Entf löscht, Strg+D dupliziert, Strg+Z macht rückgängig.
- Speichert automatisch im Browser. Über **Exportieren** / **Importieren** (JSON-Datei) lässt sich die Planung weitergeben oder sichern.
- **Drucken** gibt die aktuelle Seite verkleinert auf A4 aus.

Hinweis: Die automatische Speicherung liegt nur im jeweiligen Browser. Zum Austausch im Team die Planung exportieren und die Datei weitergeben.

Eine gemeinsame Online-Version (alle sehen dieselbe Planung live) läuft als claude.ai-Artifact aus derselben Quelle; diese Datei ist die Offline-Variante mit Drucken.
